## 1. 골프 8 (Golf 8) – 해치백의 교과서

폭스바겐의 간판 모델 골프는 1974년 1세대 출시 이후 전 세계 누적 판매 3,500만 대를 돌파한 베스트셀러입니다. 8세대 골프는 디젤(2.0 TDI)과 가솔린(1.5 TSI) 두 가지 파워트레인으로 국내에서 판매되며, 2025년 6월에는 고성능 모델 **GTI**(265ps)가 추가됐습니다.

### 골프 8 제원 (2.0 TDI 기준)

| 항목 | 수치 |
|------|------|
| 배기량 | 1,968cc (직렬 4기통 터보 디젤) |
| 최고출력 | 150ps (110kW) / 3,000~4,200rpm |
| 최대토크 | 36.7kgf·m (360Nm) / 1,600~2,750rpm |
| 변속기 | 7단 DSG |
| 연비 (복합) | 17.8km/L |
| 연비 (도심) | 15.2km/L |
| 연비 (고속) | 21.0km/L |
| 0→100km/h | 8.4초 |
| 최고속도 | 223km/h |
| 전장 | 4,285mm |
| 전폭 | 1,790mm |
| 전고 | 1,455mm |
| 축거 | 2,636mm |
| 공차중량 | 1,489kg |

### 골프 8 가격 (트림별)

| 트림 | 가격 |
|------|------|
| 프리미엄 (2.0 TDI) | 4,067만원 |

> **GTI 특이사항**: 2.0 TSI 195kW(265ps), 최대토크 370Nm, 0→100km/h 5.9초, 최고속도 250km/h(리미터)

## 2. 티구안 3세대 (Tiguan Mk3) – 패밀리 SUV 정석

2023년 말 공개된 3세대 티구안은 **MQB Evo 플랫폼** 기반으로 완전히 새롭게 설계됐습니다. 차체가 더 커지고 인포테인먼트 시스템이 대폭 향상됐으며, 플러그인 하이브리드(eHybrid) 모델도 라인업에 포함됩니다.

### 티구안 3세대 제원 (2.0 TDI 기준)

| 항목 | 수치 |
|------|------|
| 배기량 | 1,984cc (직렬 4기통 터보 디젤) |
| 최고출력 | 150ps (110kW) |
| 최대토크 | 36.7kgf·m (360Nm) / 1,750~3,250rpm |
| 변속기 | 7단 DSG |
| 연비 (복합) | 15.6km/L |
| 연비 (도심) | 14.2km/L |
| 연비 (고속) | 17.6km/L |
| 0→100km/h | 9.2초 |
| 최고속도 | 207km/h |
| 전장 | 4,510mm |
| 전폭 | 1,840mm |
| 전고 | 1,635mm |
| 축거 | 2,680mm |
| 공차중량 | 1,730kg |

### 티구안 3세대 주요 변화

- **IDA 지능형 주행 보조**: 차선 유지·교통체증 보조 기본 탑재
- **Discover Pro 내비**: 15인치 터치스크린 및 무선 CarPlay·Android Auto
- **선택형 3열 시트**: 올스페이스 버전으로 7인승 구성 가능
- **eHybrid**: 1.5 TSI + 85kW 전기모터 조합, 총 272ps, 전기 전용 주행 최대 100km(WLTP)

> 3세대 티구안의 국내 공식 출시 가격은 폭스바겐 코리아 공식 홈페이지 ([www.volkswagen.co.kr](https://www.volkswagen.co.kr))에서 확인을 권장합니다.

## 3. ID.4 – 폭스바겐 첫 순수 전기 SUV

ID.4는 폭스바겐의 전기차 전용 플랫폼 **MEB**를 기반으로 한 순수 전기 SUV입니다. 82kWh 대용량 배터리와 넉넉한 실내 공간으로 국내 전기 SUV 시장에서 꾸준한 인기를 얻고 있으며, 국고보조금 적용 시 실구매가가 크게 낮아집니다.

### ID.4 제원 (Pro 단모터 기준)

| 항목 | 수치 |
|------|------|
| 배터리 용량 | 82kWh (순 77kWh) |
| 최고출력 | 210ps (150kW) |
| 최대토크 | 31.6kgf·m (310Nm) |
| 구동 방식 | 후륜 단모터 |
| 복합 전비 | 4.9km/kWh |
| 도심 전비 | 5.0km/kWh |
| 고속 전비 | 4.8km/kWh |

| 0→100km/h | 8.5초 |
| 최고속도 | 160km/h |

| 전폭 | 1,852mm |

| 공차중량 | 2,124kg |

## 어떤 폭스바겐을 선택할까?

| 모델 | 추천 대상 | 핵심 장점 | 가격대 |
|------|----------|----------|--------|
| 골프 8 (디젤) | 연비 중시 직장인·1~2인 가구 | 탁월한 연비·알뜰한 유지비 | 4,067만원~ |
| 골프 GTI | 드라이빙 재미 추구 | 265ps 고성능 + 실용성 | 5,175만원 |
| 티구안 3세대 | 패밀리·SUV 선호자 | 넉넉한 공간·첨단 안전사양 | 5,000만원대~ |
| ID.4 | 전기차 전환 검토 중 | 보조금 활용·낮은 유지비 | 보조금 후 약 4,600만원~ |

**결론**: 연비와 운전 재미를 원한다면 **골프 8**이, 가족 공간과 미래지향성을 원한다면 **티구안 + ID.4** 조합 검토가 현명합니다. 특히 ID.4는 2026년 국고보조금 적용 시 실구매가가 크게 떨어지므로 지자체 추가 보조금까지 꼭 확인해보세요.
