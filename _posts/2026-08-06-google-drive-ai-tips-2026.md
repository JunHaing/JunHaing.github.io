## 1. Gemini로 문서 요약받기

긴 보고서나 회의 자료를 열지 않고도 핵심만 뽑아볼 수 있습니다.

| 단계 | 방법 |
|------|------|
| ① | 드라이브에서 파일 우클릭 → **"Gemini에게 요약 요청"** |
| ② | 문서 안에서도 우측 사이드바 Gemini 아이콘 클릭 가능 |
| ③ | "이 문서에서 숫자 데이터만 정리해줘" 같은 후속 질문 가능 |

PDF, 워드, 슬라이드 파일 모두 지원되며, 긴 회의록도 3~5줄로 압축해줍니다.

## 2. 자연어로 파일 검색하기

파일명이 기억나지 않아도 괜찮습니다. 검색창에 아래처럼 입력하면 됩니다.

- "지난달에 김대리가 공유한 예산 파일"
- "표가 들어있는 프레젠테이션 중에 최신 것"
- "3월에 수정한 계약서 초안"

기존 키워드 검색보다 정확도가 높고, 파일 내용까지 분석해서 찾아줍니다.

## 3. 회의록 자동 정리 + 캘린더 연동

구글 미트로 회의를 진행하면 Gemini가 자동으로 회의록을 만들어 드라이브에 저장합니다.

| 기능 | 설명 |
|------|------|
| 자동 요약 | 회의 종료 즉시 핵심 내용 요약본 생성 |
| 할 일 추출 | 대화 중 언급된 작업을 To-do 목록으로 정리 |
| 캘린더 연동 | 추출된 일정을 캘린더에 자동 등록 제안 |

별도 메모 없이 회의에만 집중해도 기록이 남는다는 점이 가장 큰 장점입니다.

## 4. 저장공간 관리도 AI가 대신

무료 15GB 용량이 부족하다면 Gemini에게 정리를 맡겨보세요.

1. 드라이브 → 설정 → **저장용량 관리**
2. "큰 파일 중 1년 이상 열지 않은 것 정리해줘" 요청
3. AI가 삭제 후보 목록을 제시하면 검토 후 일괄 삭제

수동으로 하나씩 확인하는 것보다 훨씬 빠르고, 실수로 중요한 파일을 지울 위험도 줄어듭니다.

## 5. 스마트 정리 폴더 활용

파일이 쌓이면 Gemini가 내용 기반으로 폴더 분류를 제안합니다. 사진, 영수증, 계약서 등 성격이 비슷한 파일을 자동으로 묶어주므로, 매번 수동으로 폴더를 만들 필요가 줄어듭니다.

## 핵심 정리

| 기능 | 활용 포인트 |
|------|------------|
| 문서 요약 | 우클릭 → Gemini 요약 요청 |
| 자연어 검색 | 문장 형태로 검색창에 입력 |
| 회의록 자동화 | 구글 미트 사용 시 자동 저장 |
| 저장공간 관리 | AI에게 정리 후보 요청 |
| 스마트 폴더 | 내용 기반 자동 분류 제안 |

2026년 구글 드라이브는 "저장"보다 "정리와 검색"에 방점이 찍혀 있습니다. 오늘 소개한 기능 중 하나만 적용해도 자료 찾는 시간이 눈에 띄게 줄어들 것입니다.
